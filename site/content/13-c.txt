title: Talking to C
part: Go
summary: Call a C library, and be called back.
---
```raz Qsort run
```

An `extern` procedure is found by its name in the C library, or in a library a `link` line names. Its parameters are integers, reals, pointers and procedures, as C declares them; a raz procedure of such types can be given to C to call back, as `order` is.

A program that uses C is linked against it dynamically and starts through it; one that doesn't is a static executable with nothing in it but its own code.
