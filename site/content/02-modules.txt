title: Modules
part: Raz
summary: Exports, renaming, and a body that runs first.
---
A program is a set of modules. Here is one, saved as `Greet.raz`:

```raz Greet
```

and a program beside it that uses it:

```raz Twice run
```

A name with `*` is exported; any other is the module's own. `G := Greet` imports `Greet` under a shorter name. Another module may read `G.count`, but only `Greet` may change it.

The statements after a module's last `begin` are its body. It runs once, before `main`, which is why "Greet is ready" comes first.
