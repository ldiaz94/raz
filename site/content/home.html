raz

A small systems language in Wirth’s tradition, for x86-64 Linux. Raz is Polish for one, as in counting.

Take the tour: Raz, Set, Go More Raz Download Read the report

A raz program can lay a record over a device’s registers, read and write memory exactly as written, take part in lock-free algorithms, make system calls and call C libraries. It has no garbage collector and no hidden run time: what the program does is what its text says.

The compiler is one Free Pascal program of about 9,100 lines. It makes x86-64 machine code and the ELF file itself, with no assembler or linker, in one pass, at about 900,000 lines a second.

What it has

  • Integers of 8 to 64 bits, signed and unsigned, which wrap; BOOL, F32, F64. Nothing converts unless it is written.
  • Arrays, checked slices, pointers, records laid out as C lays them out, packed records, enumerations, sets, and variants with match.
  • Every index and slice is checked; a failure says where it was, with the values, and the calls under way.
  • Every variable starts at zero. Behaviour is defined everywhere but through pointers.
  • No garbage collector: memory comes from an allocator the program chooses and passes.
  • Several results, ERROR values and defer, in place of exceptions.
  • Modules with bodies, and generic modules: Map(K, V; hash, eq).
  • ^VOLATILE T and the atomics CAS, XCHG, XADD, FENCE, for devices and lock-free code.
  • extern procedures and variables from C, code procedures in assembly, and SYSCALL.
  • Threads without C, a library of Out, Str, Bytes, Fmt, Map, Sort and more, and gdb that knows your lines.
  • A formatter, a documentation tool, and editor support for vim and emacs.

Learn it

Raz, Set, Go is a tour of the language in 15 lessons, each with programs you can run. More Raz is the second tour: the library, programs with no run time, procedures in assembly, system calls, volatile accesses, atomics and lock-free code, in 18 more.

The language, in writing

The language is defined by the report, which is short on purpose: whatever it doesn’t allow, raz doesn’t have.

Download

raz @VERSION@ is a tarball for x86-64 Linux with the compiler, raz, its library, lib/, which it finds beside itself, the formatter and the documentation tool as sources in tools/, and the manual pages. It needs nothing else installed.

Download raz @VERSION@ SHA-256 
$ tar xzf @TARBALL@
$ ln -s $PWD/@DIR@/raz ~/.local/bin/raz
$ raz run Hello.raz

The link works since raz finds lib/ beside its real path. The manual pages are in man/: man ./man/raz-tutorial.7. The address download/latest always leads to the newest release, and download/raz-@VERSION@-linux-x86_64.tar.gz to this one, for good. Earlier releases: @EARLIER@; each has its SHA-256 beside it, with .sha256 added to its name.
