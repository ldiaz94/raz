Arrays, slices and strings

Slices.raz
module Slices;
import Out, Str;

proc sum(s: []INT): INT;
var i, t: INT;
begin
    t := 0;
    for i := 0 to LEN(s) - 1 do t := t + s[i]; end;
    return t;
end;

proc main*;
var a: [5]INT; i: INT; s: []U8; name: [8]U8;
begin
    for i := 0 to 4 do a[i] := i * i; end;
    Out.int(sum(a)); Out.ln;        (* the array, as a slice *)
    Out.int(sum(a[1..3])); Out.ln;  (* a[1] and a[2] *)
    s := "hello, world";
    Out.str(s[7..LEN(s)]); Out.ln;
    if s[0..5] = "hello" then Out.str("it says hello\n"); end;
    Out.int(Str.find(s, "world")); Out.ln;
    name := "raz";                  (* a copy, the program's own *)
    name[0] := 'R';
    Out.str(name[0..3]); Out.ln;
end;

end Slices.

[5]INT is an array: five INTs in a row, copied when it is assigned. []INT is a slice: a pointer to elements that live elsewhere, and their number, LEN(s). a[lo..hi] is the slice of the elements from lo up to, but not including, hi, and an array goes silently where a slice is wanted.

A string is a slice of bytes, []U8, in UTF-8, and its bytes are constant; a [8]U8 made from one is a copy. Arrays and slices of integers compare with = and #; Str has the rest: ordering, finding, hashing and reading a number.

A for loop takes its bounds once, and never steps past the last: with an empty slice, 0 to LEN(s) - 1 doesn't run at all.
