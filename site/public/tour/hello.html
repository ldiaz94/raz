Hello, world

Every raz program is a module with a main procedure. This is the smallest one that does something.

Hello.raz
module Hello;
import Out;

proc main*;
begin
    Out.str("hello, world\n");
end;

end Hello.
hello, world

A module lives in a file of its own name, Hello.raz, and its name comes again after its last end. import Out lets it use what the module Out exports, as Out.str.

The * after main exports it; the program starts at the main of the module named on the command line. Every statement ends in ;, even one that ends in end.

Compile it and run it with raz Hello.raz && ./Hello, or with raz run Hello.raz, which writes no file.

Save a program under its module’s name and run it with raz run Name.raz.
