Modules

A program is a set of modules. Here is one, saved as Greet.raz:

Greet.raz
module Greet;
import Out;

var count*: INT;    (* the greetings so far *)

proc hello*(name: []U8);
begin
    Out.str("hello, ");
    Out.str(name);
    Out.ln;
    INC(count);
end;

begin
    Out.str("Greet is ready\n");
end Greet.

and a program beside it that uses it:

Twice.raz
module Twice;
import Out, G := Greet;

proc main*;
begin
    G.hello("world");
    G.hello("raz");
    Out.int(G.count);
    Out.str(" greetings\n");
end;

end Twice.
Greet is ready
hello, world
hello, raz
2 greetings

A name with * is exported; any other is the module's own. G := Greet imports Greet under a shorter name. Another module may read G.count, but only Greet may change it.

The statements after a module's last begin are its body. It runs once, before main, which is why "Greet is ready" comes first.

Save a program under its module’s name and run it with raz run Name.raz.
