Talking to C

Qsort.raz
module Qsort;
import Out, Fmt;

link "libm.so.6";

extern proc qsort(base: ^U8; n, size: UINT;
    less: proc(a, b: ^U8): I32);
extern proc cbrt(x: F64): F64;

(* the order of two INTs, as C's qsort wants it *)
proc order(a, b: ^U8): I32;
var x, y: ^INT;
begin
    x := ^INT(a);
    y := ^INT(b);
    if x^ < y^ then return -1; elsif x^ > y^ then return 1; end;
    return 0;
end;

proc main*;
var a: [5]INT; i: INT;
begin
    a := [30, 10, 50, 20, 40];
    qsort(^U8(ADR(a)), LEN(a), SIZE(INT), order);
    for i := 0 to 4 do Out.int(a[i]); Out.char(' '); end;
    Out.ln;
    Fmt.print("{}\n", [Fmt.real(cbrt(27.0), 3)]);
end;

end Qsort.
10 20 30 40 50 
3.000

An extern procedure is found by its name in the C library, or in a library a link line names. Its parameters are integers, reals, pointers and procedures, as C declares them; a raz procedure of such types can be given to C to call back, as order is.

A program that uses C is linked against it dynamically and starts through it; one that doesn't is a static executable with nothing in it but its own code.

Save a program under its module’s name and run it with raz run Name.raz.
