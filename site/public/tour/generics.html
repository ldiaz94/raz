Generic modules

A module may take types, and the procedures it needs on them, as parameters. Biggest.raz:

Biggest.raz
module Biggest(T; less: proc(a, b: T): BOOL);

(* the biggest of s, which mustn't be empty *)
proc max*(s: []T): T;
var i: INT; m: T;
begin
    m := s[0];
    for i := 1 to LEN(s) - 1 do
        if less(m, s[i]) then m := s[i]; end;
    end;
    return m;
end;

end Biggest.

and a program that uses it:

Generics.raz
module Generics;
import Out, Ints := Biggest(INT, before),
    Words := Biggest([]U8, shorter), Order := Sort(INT, before);

proc before(a, b: INT): BOOL;
begin
    return a < b;
end;

proc shorter(a, b: []U8): BOOL;
begin
    return LEN(a) < LEN(b);
end;

proc main*;
var a: [5]INT; i: INT;
begin
    a := [3, 1, 4, 1, 5];
    Out.int(Ints.max(a)); Out.ln;
    Out.str(Words.max(["a", "tree", "is"])); Out.ln;
    Order.sort(a);
    for i := 0 to 4 do Out.int(a[i]); Out.char(' '); end;
    Out.ln;
end;

end Generics.

Each import with its own arguments makes an instance: the module compiled again, with T standing for the type given, and less calling the procedure given. The arguments may name what the importing module declares later, as before is here.

The library's List, Map and Sort are generic modules: import Count := Map([]U8, INT, Str.hash, Str.eq);

Save a program under its module’s name and run it with raz run Name.raz.
