Raz, Set, Go

A tour of raz, in the spirit of A Tour of Go. Each lesson is one idea and a whole program, and the output shown is what the program printed when this page was made.

It is in three parts, as one counts off: Raz (one), the first steps; Set, how data is laid out; and Go, making programs that run, fail and finish well. To follow along, get raz and run any program with raz run Name.raz.

Raz

  1. Hello, world A module, an import and a procedure.
  2. Modules Exports, renaming, and a body that runs first.
  3. Values and conversions Sized integers that wrap, and nothing converts unasked.
  4. Procedures and several results Return two values, change a variable, pass a procedure.

Set

  1. Arrays, slices and strings Five in a row, a window onto them, and bytes in UTF-8.
  2. Records and pointers Laid out as C lays out a struct, reached through ^.
  3. Enumerations, sets, variants and match Choices the compiler can check you handled.
  4. Memory and allocators No garbage collector; you choose where memory comes from.

Go

  1. Errors A second result, compared by identity. No exceptions.
  2. Defer Clean up beside the line that needs it.
  3. When it goes wrong Every index is checked, and a failure tells you everything.
  4. Generic modules A module that takes types and procedures as arguments.
  5. Talking to C Call a C library, and be called back.
  6. Threads Native threads, atomics and a mutex.
