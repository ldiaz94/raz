Procedures and several results

Procs.raz
module Procs;
import Out;

proc divmod(a, b: INT): (INT, INT);
begin
    return a div b, a mod b;
end;

proc swap(var a, b: INT);
var t: INT;
begin
    t := a;
    a := b;
    b := t;
end;

proc square(n: INT): INT;
begin
    return n * n;
end;

proc twice(f: proc(n: INT): INT; n: INT): INT;
begin
    return f(f(n));
end;

proc main*;
var q, r, x, y: INT;
begin
    q, r := divmod(17, 5);
    x := 1;
    y := 2;
    swap(x, y);
    Out.int(q); Out.char(' '); Out.int(r); Out.ln;
    Out.int(x); Out.char(' '); Out.int(y); Out.ln;
    Out.int(twice(square, 3)); Out.ln;
    _, r := divmod(-7, 2);
    Out.int(r); Out.ln;
end;

end Procs.

A parameter is a copy, unless it is var, when it is the caller's variable itself. A procedure may return several results, which a multiple assignment takes apart; the blank, _, drops one.

A procedure is a value too, of a procedure type, as f is in twice. A procedure without parameters leaves out the parentheses, as Out.ln does. Procedures don't nest, and a name is declared before it is used.

Save a program under its module’s name and run it with raz run Name.raz.
