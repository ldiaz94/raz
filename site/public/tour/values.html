Values and conversions

Values.raz
module Values;
import Fmt;

const Max = 100;    (* untyped: it takes the type it meets *)

proc main*;
var n: INT; b: U8; big: I64; x: F64; c: I32; ok: BOOL;
begin
    n := Max * 3;
    b := 250;
    b := b + 10;          (* wraps, in a U8: 4 *)
    big := n;             (* an INT goes into an I64 *)
    x := F64(n) / 7.0;    (* nothing else converts unasked *)
    c := '\u{E9}';        (* a character is its code point *)
    ok := (n > Max) and (b # 0);
    Fmt.print("{} {} {} {} {} {}\n", [Fmt.int(n), Fmt.int(I64(b)),
        Fmt.int(big), Fmt.real(x, 3), Fmt.int(I64(c)),
        Fmt.bool(ok)]);
end;

end Values.
300 4 300 42.857 233 true

The integers are I8, I16, I32, I64 and U8, U16, U32, U64, and INT and UINT, as big as an address. INT is the everyday one: lengths, indexes and counts are INTs. The reals are F32 and F64.

Arithmetic wraps at the type's width and never stops the program, except dividing by zero. That is why 250 + 10 in a U8 is 4.

Two types never mix: with i: I64, i < LEN(s) is an error. A type's name converts, as F64(n) and I64(b) do above. The one silent conversion between numbers is an INT into an I64, which loses nothing.

#, not <>, is "different". and, or and not are for BOOLs; &, |, xor and ~ are for the bits of integers. Every variable starts at zero.
