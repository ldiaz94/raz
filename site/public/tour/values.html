Values and conversions

Values.raz
module Values;
import Fmt;

const Max = 100;    (* untyped: it takes the type it meets *)

proc main*;
var n: INT; b: U8; big: I64; x: F64; c: I32; ok: BOOL;
begin
    n := Max * 3;
    b := 250;
    b := b + 10;          (* wraps, in a U8: 4 *)
    big := n;             (* an INT goes into an I64 *)
    x := F64(n) / 7.0;    (* nothing else converts unasked *)
    c := '\u{E9}';        (* a character is its code point *)
    ok := (n > Max) and (b # 0);
    Fmt.print("{} {} {} {} {} {}\n", [Fmt.int(n), Fmt.int(I64(b)),
        Fmt.int(big), Fmt.real(x, 3), Fmt.int(I64(c)),
        Fmt.bool(ok)]);
end;

end Values.
300 4 300 42.857 233 true

Integers

The integers are I8, I16, I32, I64 and U8, U16, U32, U64, and INT and UINT, as big as an address. INT is the everyday one: lengths, indexes and counts are INTs.

Arithmetic wraps at the type's width and never stops the program, except dividing by zero. That is why 250 + 10 in a U8 is 4. div divides toward zero, and mod has the sign of its left side.

Wrap.raz
module Wrap;
import Out;

proc main*;
var a: U8; b: I8; c: U32; d: INT;
begin
    a := 250;  a := a + 10;
    Out.int(I64(a)); Out.ln;           (* 4 *)
    b := 127;  b := b + 1;
    Out.int(I64(b)); Out.ln;           (* -128 *)
    c := 0;    c := c - 1;
    Out.int(I64(c)); Out.ln;           (* 4294967295 *)
    d := -7;
    Out.int(d div 2); Out.str(" ");    (* -3 *)
    Out.int(d mod 2); Out.ln;          (* -1 *)
end;

end Wrap.
4
-128
4294967295
-3 -1

Conversions are written

Two types never mix: with i: I64 and a slice s, i < LEN(s) is an error. A type's name converts: F64(n), I64(b), U8(x). Converting to a narrower integer cuts it; to a wider one extends it by its sign (signed) or with zeros (unsigned). The one silent conversion between numbers is an INT into an I64, which loses nothing.

A number written in the program is untyped until it meets a type; 0FFH is hexadecimal, and 1.5 is a real, which an integer never becomes without a conversion.

Mix.raz
module Mix;
import Out;

proc main*;
var i: I64; s: []U8;
begin
    s := "four";
    i := 3;
    if i < LEN(s) then Out.str("smaller\n"); end;
end;

end Mix.
$ raz Mix.raz

The fix is the conversion, written where it happens: if i < I64(LEN(s)). It costs nothing at run time and says what is meant.

Bits and booleans

#, not <>, is "different". and, or and not are for BOOLs, and bind below the relations, so i < n and a[i] # 0 needs no parentheses. &, |, xor, ~, shl and shr are for the bits of integers. There is no conversion between BOOL and an integer: say what you mean with if.

Bits.raz
module Bits;
import Out;

proc main*;
var flags, mask: U8;
begin
    flags := 0;
    flags := flags | 1;               (* set bit 0 *)
    flags := flags | (1 shl 3);       (* set bit 3 *)
    mask := 0FH;
    Out.str("flags 0x"); Out.hex(U64(flags), 2); Out.ln;
    Out.str("and   0x"); Out.hex(U64(flags & mask), 2); Out.ln;
    Out.str("xor   0x"); Out.hex(U64(flags xor 0FFH), 2); Out.ln;
    Out.str("not   0x"); Out.hex(U64(~flags), 2); Out.ln;
    if (flags & 8) # 0 then Out.str("bit 3 is set\n"); end;
end;

end Bits.

Reals

F32 and F64 are the reals. A real constant is written with a point, 1.5 or 2.0E-3. Fmt.real(x, places) writes one with that many digits after the point, and Math has the functions.

Reals.raz
module Reals;
import Fmt, Math;

proc main*;
var n: INT; x: F64; y: F32;
begin
    n := 22;
    x := F64(n) / 7.0;
    y := F32(x);
    Fmt.print("22/7 = {}\n", [Fmt.real(x, 6)]);
    Fmt.print("as F32 = {}\n", [Fmt.real(F64(y), 6)]);
    Fmt.print("sqrt 2 = {}, pi = {}\n", [Fmt.real(Math.sqrt(2.0), 5), Fmt.real(Math.pi, 5)]);
    Fmt.print("truncated: {} {}\n", [Fmt.int(I64(2.9)), Fmt.int(I64(-2.9))]);
end;

end Reals.
22/7 = 3.142857
as F32 = 3.142857
sqrt 2 = 1.41421, pi = 3.14159
truncated: 2 -2

A real converts to an integer by rounding toward zero. Every variable starts at zero, a real's 0.0 and a BOOL's false included, so there is no uninitialised value to be surprised by.
